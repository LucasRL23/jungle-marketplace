# Artwork provenance

These four artworks are the original PNG images supplied in the Jungle challenge Figma file:
https://www.figma.com/design/Ff0SksUi7UFtPWUO8kyNtw/Frontend-Challenge

They were downloaded from image resources actually loaded by the reference file, and resized with Sharp 0.35.5 to WebP (quality 86, effort 5). No generative replacements were used.

| Local artwork | Figma image resource |
| --- | --- |
| ape-1 | 092751c0e05e0ed9 |
| ape-2 | 7984697abe13ef08 |
| ape-3 | 6fe83faf9f8917b5 |
| ape-4 | 776ef9f1c182be40 |

Each is provided at 240, 480 and 960 pixels. The app uses responsive `srcSet` images. The source PNGs were 1254 × 1254 pixels. Expiring signed download URLs are intentionally excluded.

The file supplies four distinct loaded artworks; additional demo products reuse those images. Product entries after the first reference cards are illustrative fixtures. Roboto Mono is a self-hosted, OFL-licensed approximation of the reference typography; its exact family has not yet been confirmed from Figma metadata.
